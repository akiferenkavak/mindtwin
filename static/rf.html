How Grey-Box Random Forest Detection Works

This model combines physics-informed features (joint kinematics) with a data-driven BaggingRegressor to predict expected torques. Anomalies are detected when actual torques deviate significantly from predictions.

01

Kinematic Feature Extraction

AXIS_ACT data is parsed to extract 6 joint angles (q₁…q₆) in radians. VEL_AXIS_ACT columns provide measured velocities (deg/s → rad/s) or Savitzky-Golay gradient is applied.

02

Grey-Box Feature Vector

Feature vector X = [q₁…q₆, q̇₁…q̇₆, curr₁…curr₆, τ_model_j]. The physics-based torque from Recursive Newton-Euler inverse dynamics (URDF) is the grey-box component.

03

BaggingRegressor Prediction

Six separate models (one per axis A1–A6) predict the expected normalized torque τ̂ᵢ. 100 decision-tree estimators, trained on 80% of data.

04

Residual & Threshold

Residual rᵢ = |τᵢ_actual − τ̂ᵢ|. Thresholds: thr = mean(|rᵢ|) + 3·std(|rᵢ|) on held-out 20% validation set.

05

Anomaly Decision

If rᵢ > thrᵢ for any axis i ∈ {A1…A6}, an anomaly is flagged. The worst joint (highest ratio rᵢ/thrᵢ) is reported for diagnosis.

06

BRAKE_SIG Filtering

Training only used frames where BRAKE_SIG == 63 (brakes released, robot in motion). This excludes idle/clamped states.
